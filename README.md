
# To-Do List App

**Name:** Abigail Jim G. Lapinid
**Section:** IT3R4

## Description
A simple Python program that allows users
to add tasks and view their to-do list.

## Features
- Add tasks
- View tasks
- Exit the program

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `python todo_list.py`.
5. Choose an option from the menu.
